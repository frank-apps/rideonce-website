# 一次叫車

[一次叫車](https://frank-apps.github.io/rideonce-website/)（RideOnce）官方說明站：介紹與操作說明、隱私權政策、支援。

## 這個 App 做什麼

- 起點與迄點只填一次，在地圖上看開車路線與路況。
- 依各縣市公告費率估算**小黃跳表參考**車資；不是任何平台的即時報價。
- 轉去 yoxi、LINE GO、Bolt、台灣大車隊 55688、Uber 等叫車 App；Uber 可帶入起訖，其他 App 可一鍵複製迄點。與各平台無合作或代表關係。
