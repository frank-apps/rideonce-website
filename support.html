常見問題

今天的次數用完了怎麼辦？

新路線試算與新地點搜尋各有每日免費次數，隔天會重置。用完時可以觀看廣告增加次數；已經搜尋過的地點，可以直接從「最近搜尋」選，不會用掉搜尋次數。

怎麼清除搜尋記錄？

在搜尋頁的「最近搜尋」按「清除搜尋記錄」。記錄只存在這台手機。

點了平台卻跳到 App Store？

代表這台手機沒有安裝該平台的 App。安裝後回到一次叫車再點一次即可；迄點名稱已經複製，可以直接貼上。

為什麼有時候平台卡片沒有價格區間？

尖峰時段各平台會依當下運力加價，路況延滯偏高時固定車資波動也大，這些時候我們無法合理推估，所以不顯示區間。上方的小黃跳表參考仍可參考，實價請到該 App 查看。

為什麼這裡的車資和平台 App 不一樣？

一次叫車的數字是依公開跳表費率估算的參考，不是任何平台的即時報價。各平台的優惠、加價與實際路線都會讓金額不同，請以該 App 顯示為準。

為什麼顯示「費率：未核對縣市」？

該縣市的公告費率還沒有核對，日間跳表先用已核對縣市的中位數估算，未套用夜間與春節加成。實際以車上跳表為準。

位置不準或沒有顯示目前位置？

請到「設定 → 隱私權與安全性 → 定位服務 → 一次叫車」選擇「使用 App 期間」，並開啟「精確位置」。

FAQ

I used up today’s tries. What now?

New route estimates and new place searches each have a free daily allowance that resets the next day. You can watch an ad for more tries, or pick a place you already searched from Recent searches, which does not use a search.

How do I clear search history?

On the search screen, under Recent searches, tap “Clear search history”. History is stored only on this phone.

Tapping a provider opens the App Store.

That provider’s app is not installed on this phone. Install it, return to RideOnce, and tap again. The drop-off name is already copied, so you can paste it.

Why do some provider cards show no price range?

At peak times providers add supply-based pricing, and in heavy delay fixed fares swing widely, so we cannot estimate a fair range. The meter-taxi reference above still applies; check the provider’s app for the real fare.

Why does the fare differ from the provider’s app?

RideOnce estimates from published meter rates. It is a reference, not a live quote from any provider. Promotions, surge pricing, and the actual route all change the amount; the provider’s app is authoritative.

What does “Tariff: unpublished county” mean?

That county’s published tariff has not been verified yet, so the daytime meter uses the median of verified counties, without night or Lunar New Year extras. The meter in the taxi is authoritative.

My location is wrong or missing.

Go to Settings → Privacy & Security → Location Services → RideOnce, choose “While Using the App”, and turn on Precise Location.
